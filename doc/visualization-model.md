# 可视化空间数学模型（v0.1，2026-08-31）

> 本文件定义「研究方向图谱」的数学基础：图上点与区间的**距离/半径/布局**如何定义与求解，
> 以及反过来要求 skill 中的 LLM 产出哪些评分。实现（analyze/layout.py、导出、插件渲染）以此为契约。

## 1. 对象与目标

图上承载三层对象：**方向（区域）**、**论文（点）**、**研究者（点）**。
图要可读出的信息：

1. 论文/研究者与某方向有多"近"（语义关联）——**距离**
2. 论文/研究者有多重要——**节点半径**（受约束的物理量）
3. 方向之间的关系（相关/覆盖）——**区域的空间分布与重叠**
4. 论文的跨方向性——**主方向 + 次方向连线/偏移**

集合记号：方向 `D={1..K}`（首批 K=12 已命名主方向）；方向 i 的域内论文 `P_i`、
可空间化子集 `P_i^c ⊆ P_i`；研究者 `A`、核心可空间化子集 `A^c ⊆ A`。坐标空间 R²。

## 2. 距离（语义度量，由 LLM 评分观测）

| 量 | 定义 | 来源 |
|---|---|---|
| 论文-方向关联度 `a(j,i) ∈ [0,1]` | 论文 j 在多大程度上代表/属于方向 i | LLM（direction_affinity，锚定理由） |
| 方向-方向关联度 `s(i,i′) ∈ [0,1]` | 方向 i 与 i′ 主题相关/覆盖程度 | LLM（direction_map） |
| 论文-方向距离（方向内径向） | `d(j,i*) = R_{i*} · (1 − a(j,i*))`（主方向） | 派生 |
| 研究者-方向 | 由其论文聚合（质心）或显式评分 | 派生（默认聚合） |

**红线**：距离只用 LLM 语义评分；被引/共著等物理量不得充当距离（仅用于半径）。

## 3. 节点半径（受约束物理量）

- 语义：重要性（论文=影响力；研究者=活跃度/影响力）
- **约束**：有明确上下界 `[r_min, r_max]`（如画布/区域半径比例的 2%–15%），映射单调、抗长尾
- 论文 `r_p(j) = r_min + (r_max − r_min)·u_j^γ`
  - `u_j = α·cite_rank_pct(j) + β·core_frac(j)`，α+β=1（默认 α=0.7, β=0.3）
  - `cite_rank_pct`：被引在簇内论文中的**百分位**（秩次归一，抗长尾）
  - `core_frac`：论文作者中属于该簇核心成员的比例（≤1）
  - `γ≈0.7–1.0`：控制分布形状（实施时校准）
- 研究者 `r_a = r_min + (r_max−r_min)·f(论文数分位, 总被引分位)`，同类约束映射

## 4. 方向区域与区间

1. **原点基线（按热度加权角度分配）**：无关联信息时方向中心默认分布于原点周围，**角度扇区按方向热度分配**
   （热度 ∝ √规模 或热度分）：`θ 扇区 ∝ 热度_i`，热方向占更大角度、冷方向收窄；
   `c_i^0 = R_base · (cos θ_i, sin θ_i)`，θ_i 为加权累积角 + 固定相位 φ
2. **关联修正**：按 `s(i,i′)` 作受控松弛——强关联/覆盖的两方向中心相互靠近（弹簧系数 k(s)），
   但保持最小可分辨间距（防止完全重叠）；弱关联保持热度基线
3. **覆盖/包含关系**：方向间若存在主题包含（高 s），区域允许**重叠/嵌套示意**，重叠区即共享论文所在；
   冲突解决步：若 `s` 低的两方向空间过近 → 推开
4. 区域半径 `R_i`：受簇规模与**画布总空间约束**（Σ区域面积 × 密度 ≤ 可用画布 × 因子）：
   `R_i = R̄ · g(size_i)`，g 单调、饱和（大簇不无限大）

> 空间位置相互影响通过上述「基线 → 关联修正 → 冲突解决」迭代体现，迭代可复现（seed 固定）。

## 5. 论文/研究者在区间内的分布

1. **可空间化子集（降复杂度）**：
   - `P_i^c`：每方向按论文半径取 top `N_p`（15–25 篇）
   - `A^c`：每方向按研究者半径取 top `N_a`（10–15 人）
2. **空间化论文 j（主方向 i* = argmax a(j,i)）**：
   - 位置：`x_j = c_{i*} + (R_{i*}·(1 − a(j,i*)))·û(θ_j)`，径向距随关联度单调（越代表越靠中心）
   - 角向 `θ_j`：环带内确定、可复现排布（黄金角/按次要相似修正）
   - **次方向**：若 `a(j,i2) ≥ 阈值`（如 0.6），向 `c_{i2}` 方向产生受控**偏移**（不进该区间），
     并画**虚线连线**到次方向区域边界（跨方向性可视化）
3. **研究者位置**：其空间化论文位置的**加权质心**（权重=论文半径）；无空间化论文者按 a 评分
   径向置于主方向环带
4. **随机排布降复杂度**：非空间化对象（其余论文/研究者）在所属区间内**带种子随机排布**
   （确定性随机，仅存在性展示，不做精确距离）
5. 连线：研究者 ↔ 其代表论文；论文-论文共享作者 ≥ 阈值（可选开关）

## 6. 求解与存储

- `analyze/layout.py`（确定性）：输入 = 关联评分表（a、s）+ 半径参数 + seed
  → 迭代求解（均匀基线 → 关联修正 → 冲突解决 → 成员分布）→ 坐标
- 输出/存储：`node_layout`（domain, type, id, x, y, r, cluster_id, main_dir, affinity）
  落 SQLite；导出 vault（供插件静态读取）
- 全参数可复现；单次评分变更只引起局部位置变化（区域锚定）

## 7. LLM 评分原语（模型反推 → skill 任务）

| 评分 | 对象 | 规模（首批 K=12） | 模板 |
|---|---|---|---|
| `a(j,i)` 论文×方向关联度 | 每方向 `P_i^c`（top 20 篇/方向） | ≈240 篇 | direction_affinity |
| `s(i,i′)` 方向两两关联度 | K(K−1)/2 对 | 66 对 | direction_map |

- 全部 LLM 评分：锚定理由、默认待审、记录 model/prompt_ver；人工审阅后参与布局
- 半径/布局参数为确定性配置（不用 LLM）
