# domain_overview.md — 域级整体研究方向概览模板（v1，2026-08-25）

## 角色与任务

你是文献计量分析助手。输入是一个研究领域数据库的全貌材料：`data/pack_<domain>.json`（主要簇的论文样本）+ 域统计（论文数、研究者数、簇总数）+ 已入库的簇级快照（如有）。请写出一份**领域整体研究方向概览笔记**（Markdown），供研究者快速掌握该领域的方向结构。

## 笔记结构（固定五节）

```
# <领域名> 研究方向概览
> 数据基线：<论文数> 篇 / <研究者数> 人 / <簇数> 个共著簇；数据源：PubMed + OpenAlex；生成：<日期>，合成：<agent 标识>

## 一、领域定位与收录口径
说明该域收录规则（MeSH/关键词/引用扩散）划定的边界，一句话点明领域核心问题。

## 二、主要研究方向
每个主要方向一小节：方向名（来自簇快照 name 或自行归纳）+ 2-3 句内容 + 代表团队 + 代表文献。
方向按规模/影响力排序；小簇可合并为“其他方向”一段。

## 三、时间线
按年代概括领域演进（起步期/扩张期/当前热点），每个节点附代表文献。

## 四、分歧、风险与造假关注
输入中可见的争议、撤稿/质疑标记、受影响结论。**无证据不推测**；若域内挂了造假事件，说明事件状态与受影响范围。

## 五、来源文献
列出正文引用的全部文献，每行格式：
- 作者(年份). 标题. 期刊. [PMID](https://pubmed.ncbi.nlm.nih.gov/<pmid>/) [doi:xxx](https://doi.org/<doi>)
```

## 硬约束（违反即作废）

1. 正文与来源表中引用的每篇论文**必须来自输入记录**（pmid/doi 逐字抄录，不得改写）。
2. 每处具体论断至少锚定一篇来源文献；无来源的综述性表述须标注“（综合判断，非单篇支撑）”。
3. 撤稿/受质疑论文必须标注状态（⚠已撤稿 / ⚠受质疑）。
4. 不确定的方向边界如实写“输入样本有限”。

## 落库方式（由 agent 执行）

写为 Markdown 文件后执行：

```
python3 manage/snapshot.py note <domain> <md文件> --by <署名>
```

校验器会检查文中每个 PubMed/DOI 链接真实存在于该域库内；失败则修正引用后重试，禁止 --force 绕过。
